# 株価予想アプリ 設計書

- 作成日: 2026-11-01（同日改訂：Gemini を使わず、Google ニュース検索と単語辞書で分析する方式に変更）
- 状態: レビュー待ち

## 1. 目的と前提

| 項目 | 内容 |
|---|---|
| 目的 | 自分の投資判断の参考にする（個人使用のみ） |
| 対象 | 日本・米国の主要指数 ＋ 登録した個別銘柄 |
| 予測期間 | 翌営業日・1週間後（5営業日）・1か月後（21営業日）を並べて表示 |
| 予測の根拠 | ① 代表的な予測計算式（テクニカル指標）② 世界全体の動向・株式ニュース |
| 費用 | すべて無料（GitHub Actions / GitHub Pages / Google ニュース RSS / Yahoo Finance）。API キーは不要 |
| 公開形式 | HTML の静的サイト（GitHub Pages） |

### 決定事項と理由

- **ニュース・世界動向は Google ニュースの検索 RSS で集める**（`https://news.google.com/rss/search?q=...`）。Google が公式に提供している仕組みで、無料・キー不要。Google 検索の結果ページを自動で読み取るのは規約違反でブロックされるため使わない。
- **AI は使わない。** ニュースの見出しは、単語に点数を付けた辞書で点数化する（文脈は読めない）。因果のつながりは「テーマ → 市場」の影響の対応表を設定ファイルで持つことで補う。
- **株価の過去データは Yahoo Finance から取る。** 計算式には正確な数値の時系列が必要なため。
- **Apps Script は使わない**（ユーザーの指定）。
- **リポジトリは public。** サイトの URL と JSON データ（公開情報のみ）は誰でも見られる。秘密情報は扱わない。
- **法令面**：個人使用で対価を取らないため、投資助言業の登録対象ではない想定。ただし画面に免責表示を必ず出す。

### 対象

- **指数**：日経平均（`^N225`）、TOPIX（データの都合で TOPIX 連動 ETF `1306.T` で代用。画面には ETF の価格であることを表示する）、S&P500（`^GSPC`）、NASDAQ総合（`^IXIC`）、ダウ平均（`^DJI`）
- **世界の指標**（表示のみ。予測はしない）：ドル円（`JPY=X`）、WTI原油（`CL=F`）、米国10年債利回り（`^TNX`）、VIX（`^VIX`）
- **登録銘柄（初期値）**：IonQ（`IONQ`）

## 2. 全体構成

```
GitHub Actions（平日 22:00 UTC = 07:00 JST、米国市場の終了後・東証の開始前。手動実行も可）
  ├─ ① 株価取得     : Yahoo Finance から約1年分の日足終値
  ├─ ② ニュース取得 : Google ニュース RSS をテーマ・銘柄ごとに検索（日本語版・英語版）
  ├─ ③ ニュース分析 : 見出しを単語辞書で点数化し、テーマ → 市場・銘柄の点数にまとめる
  ├─ ④ 予測計算     : ① と ③ を組み合わせ、期間ごとの予測を出す
  ├─ ⑤ 的中率の更新 : 期限が来た過去の予測を実際の値と照合する
  └─ ⑥ data/ に JSON を保存して commit・push
          ↓
GitHub Pages（site/）
  ├─ data/*.json を読み込んで表示するだけ（計算はしない）
  └─ 「今すぐ再分析」：GitHub Actions の手動実行画面を開く。実行後2〜3分でサイトが更新される
```

- 言語は JavaScript（ES Modules、Node.js 22）。サイトはビルド不要の素の JavaScript。Chart.js は CDN からバージョンを固定して読み込む。
- 使うパッケージ：`yahoo-finance2`、`fast-xml-parser`（RSS の読み込み）、テスト用の `vitest` と `playwright`。

```
config/lexicon.json          単語辞書（日本語・英語）
src/core/indicators.js       SMA・EMA・RSI・MACD・ボリンジャーバンド・回帰の傾き・ボラティリティ
src/core/scoring.js          各指標の値 → −1〜+1 の点数
src/core/predict.js          点数と重み → 期間ごとの予測

src/core/newsAggregate.js    見出しの点数 → テーマ・市場・銘柄の点数
src/core/pipeline.js         銘柄データの組み立てと予測
src/collector/prices.js      Yahoo Finance から取得

```

## 3. 予測の計算方法

**方式**：点数を重み付けして合計する。各要素の寄与を画面にそのまま示せる。

### 3.1 計算式と点数（各点数は −1〜+1 に収める）

v は 20日ボラティリティ（無ければ 0.02、下限 1e-6）。

| 指標 | パラメータ | 点数 |
|---|---|---|
| 短期の移動平均 | 5日と25日 | tanh(((SMA5 − SMA25) / SMA25) / (2v)) |
| 長期の移動平均 | 50日と200日 | tanh(((SMA50 − SMA200) / SMA200) / (5v))。200日に満たなければ使わない |
| 75日移動平均との位置 | 75日 | tanh(((終値 − SMA75) / SMA75) / (3v)) |
| RSI | 14日 | (50 − RSI) / 50（売られすぎで＋、買われすぎで−） |
| MACD | 12・26・9 | tanh(((MACD − シグナル) / 終値) / (0.5v)) |
| ボリンジャーバンド | 20日・±2σ | 1 − 2×%b（下のバンドで＋1、中心で0、上のバンドで−1）。−1〜+1 で打ち切る |
| 回帰の傾き | 60日 | tanh(傾き × √60 / v)（傾きは ln(価格) の1日あたりの変化） |
| ボラティリティ | 20日 | 日次対数収益率の標準偏差。点数ではなく予測の幅に使う |

### 3.2 ニュース・世界動向（Google ニュース RSS ＋ 単語辞書）

**検索**（`config/news.json`）

- テーマは9つ：米国・日本・欧州・中国・中東・新興国・金融政策・為替・資源。テーマごとに日本語と英語の検索語を持つ。
- 登録銘柄は「{銘柄名} 株」（日本語）と「{銘柄名} stock」（英語）で検索する。
- 検索語には `when:7d` を付けて直近7日に絞る。日本語版は `hl=ja&gl=JP&ceid=JP:ja`、英語版は `hl=en-US&gl=US&ceid=US:en`。
- 1日の検索回数は（9テーマ＋登録銘柄数）×2 回程度。取得の間隔は1秒空ける。

**見出しの点数**（`config/lexicon.json`）

- 見出しの末尾の「 - 媒体名」は取り除いてから判定する。
- 日本語は部分一致、英語は大文字小文字を区別せず単語の境界で一致させる（`war` は `warning` に一致しない）。
- 見出しの点数 ＝ tanh(当てはまった単語の点数の合計)。打ち消しの語（例：「回避」「撤回」、`avoid`、`eases`）を含むときは −0.5 倍する。
- 当てはまる単語が1つもない見出しは「中立」として数えない（点数の計算から除く）。
- テーマに専用の辞書があれば、それを優先する（例：為替のテーマでは「円安 +」「円高 −」。資源のテーマでは「原油高」は日本市場に効くよう「−」）。

**まとめ方**

- 同じリンク、または同じ見出しの記事は1つにまとめる。
- 記事の重み ＝ 0.5^(経過日数 / 2)（新しい記事ほど重い。半減期2日）。
- テーマの点数 ＝ 当てはまった見出しの点数の加重平均。確信度 ＝ min(1, 当てはまった見出しの数 / 5)。
- **短期**は直近2日の見出しだけ、**中期**は7日分の見出しで計算する。
- **市場の点数**（JP・US）＝ Σ(テーマの点数 × 確信度 × 影響度) / Σ(確信度 × 影響度)。影響度は `config/news.json` の対応表（例：中東 → JP 0.4・US 0.3、金融政策 → JP 0.6・US 1.0）。
- **銘柄の点数** ＝ 銘柄の見出しの点数（重み 1 × 確信度）と、上場市場の点数（重み 0.5）の加重平均。
- 該当がなければ null（＝ニュースなしとして扱う）。

### 3.3 期間ごとの重み（`config/weights.json` の初期値）

| 期間 | 計算式全体 | ニュース全体 | 計算式の内訳 | 使うニュース |
|---|---|---|---|---|
| 翌日（1営業日） | 0.5 | 0.5 | RSI 0.35・ボリンジャー 0.35・短期移動平均 0.15・MACD 0.15 | 短期 |
| 1週間（5営業日） | 0.5 | 0.5 | MACD 0.35・短期移動平均 0.35・RSI 0.15・ボリンジャー 0.15 | 短期と中期を半分ずつ |
| 1か月（21営業日） | 0.6 | 0.4 | 長期移動平均 0.35・回帰の傾き 0.35・75日移動平均 0.30 | 中期 |

使えない指標（データ不足）があるときは、残りの指標で重みを按分し直す。ニュースが null のときは、計算式の重みを 1.0 にする。

### 3.4 予測値

- 合計点 S（−1〜+1）
- 期間の値動き幅 σh ＝ v × √h（h は営業日数）
- 予想変化率 ＝ S × σh × k（k ＝ 1.0。weights.json で調整できる）
- 予測の幅 ＝ 予想変化率 ± σh
- 方向：S ≥ 0.15 なら「上昇」、S ≤ −0.15 なら「下落」、それ以外は「横ばい」
- 確信度：符号が S と同じ要素の実効の重みの合計が 0.75 以上で「高」、0.5 以上で「中」、それ未満は「低」。S ＝ 0 のときは「低」

### 3.5 的中率

- 毎日の予測を `data/history/` に保存する（同じ日は上書き）。
- 期限（h 営業日後。銘柄ごとの取引日で数える）が来たら、実際の終値と照合する。
  - 方向の的中：上昇は実際が＋、下落は実際が−。横ばいは実際の変化率が ±σh×0.25 以内なら的中
  - 実際の値が予測の幅に入ったかどうか
- 期間ごと・銘柄ごとに集計して `data/accuracy.json` に保存する。重みの自動調整はしない。

## 4. 画面

1ページ構成。スマホとダークモードに対応する。

1. **上部**：最終更新の日時、「今すぐ再分析」ボタン（GitHub Actions の手動実行画面を新しいタブで開く。「実行後2〜3分で更新されます。終わったらこのページを再読み込みしてください」と添える）
2. **世界動向**：テーマごとの点数を色付きのカードで表示し、点数に効いた見出し（当てはまった単語を強調）と記事へのリンクを付ける
3. **世界の指標**：ドル円・原油・米国10年債利回り・VIX の現在値と前日比
4. **予測一覧の表**：銘柄・現在値・翌日・1週間・1か月（方向の矢印と予想変化率）・確信度
5. **詳細**（行をクリックすると開く）：価格チャート（終値・移動平均線・ボリンジャーバンド・予測の幅の帯）、点数の内訳、関係する見出し
6. **的中率**：期間ごとの的中率と、予測と実際の比較
7. **フッター**：免責表示「投資助言ではありません。投資の判断はご自身の責任で行ってください。」

## 5. エラー時の動き

| 状況 | 対応 |
|---|---|
| 一部の銘柄の株価が取れない | 前回の `latest.json` の値を使い、「⚠️データが古い」と表示する。ほかの銘柄の処理は続ける |
| 株価がまったく取れない | 処理を失敗として終了し、データは更新しない（GitHub から失敗のメールが届く） |
| 一部の検索が失敗する・0件 | 2回までやり直し、だめならそのテーマ・銘柄だけニュースなし（null）にする |
| すべての検索が失敗する | ニュースを使わずに予測し、「ニュースの分析なし」と表示する |
| サイトで JSON が読めない | エラーのメッセージと再読み込みのボタンを表示する |

## 6. テスト

- **`src/core/`**：テストを先に書いてから実装する。既知の数値列で各指標を、範囲・按分・方向・確信度の判定を確かめる。辞書による判定（部分一致・単語の境界・打ち消し・媒体名の除去）と、まとめ方（重複の除去・経過日数による重み・短期と中期・市場と銘柄）も確かめる。
- **collector**：Yahoo と RSS は擬似データに差し替える。RSS の読み込みは実物に似せた XML で確かめる。`run.js` が `latest.json`・`history`・`accuracy.json` を正しく書き出すかを確かめる。テスト中に実際の通信はしない。
- **サイト**：Playwright で、テスト用の JSON を置いて表示を確かめる（表・チャート・詳細の開閉・データが古い場合・ニュースなし・読み込み失敗・幅375px）。

## 7. やらないこと（今回の範囲外）

- AI による文章の理解・要約
- 自動売買・証券会社との連携
- 全銘柄の予測
- 機械学習・重みの自動調整
- サイト上での銘柄の追加（`config/watchlist.json` を編集して行う）
- サイト上からの直接の再計算（GitHub Actions の手動実行で代用する）
