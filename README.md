# 株価予想ボード

日本・米国の主要指数と登録した銘柄について、**テクニカル指標**と **Google ニュース検索の見出し**から、翌営業日・1週間後・1か月後の値動きを予想して表示する個人用のサイトです。

> **投資助言ではありません。投資の判断はご自身の責任で行ってください。**
> 単語辞書による見出しの判定は文脈を読めず、テクニカル指標も将来を保証しません。参考情報としてお使いください。

## しくみ

```
GitHub Actions（平日 日本時間 7:00 に自動実行。手動実行もできます）
  ① Yahoo Finance から約1年分の終値を取得
  ② Google ニュースの検索 RSS で、9つのテーマ（米国・日本・欧州・中国・中東・新興国・金融政策・為替・資源）と登録銘柄を日本語・英語で検索
  ③ 見出しを単語辞書で点数化し、テーマ → 市場（日本・米国）→ 銘柄の点数にまとめる
  ④ 移動平均・RSI・MACD・ボリンジャーバンド・回帰の傾きの点数とニュースの点数を、期間ごとの重みで合計して予測
  ⑤ 過去の予測を実際の値動きと照合して的中率を更新
  ⑥ data/ に JSON を保存し、GitHub Pages に公開
```

詳しい計算方法は `docs/superpowers/specs/2026-11-01-stock-predictor-design.md` を見てください。

## 初期設定（最初の1回だけ）

1. このブランチを `main` にマージします。
2. GitHub のリポジトリで **Settings → Pages** を開き、**Source** を「**GitHub Actions**」にします。
3. **Actions** タブ → 左の「**daily**」→「**Run workflow**」で手動実行します。
4. 数分後、Settings → Pages に表示される URL（`https://tennis226243-coder.github.io/test/`）でサイトが見られます。

API キーなどの登録は不要です。

## 使い方

- **再分析**：サイトの「今すぐ再分析」を押すと Actions の画面が開きます。「Run workflow」を押し、2〜3分後にサイトを再読み込みしてください。
- **銘柄の追加**：`config/watchlist.json` の `stocks` に追加します。東証の銘柄は `.T` を付けます。

  ```json
  { "symbol": "7203.T", "name": "トヨタ自動車", "market": "JP" }
  ```

  `name` はニュースの検索語（「トヨタ自動車 株」「トヨタ自動車 stock」）にも使われます。
- **検索語・影響度の調整**：`config/news.json`（テーマごとの検索語、日本市場・米国市場への影響度、テーマ専用の辞書）
- **単語辞書の調整**：`config/lexicon.json`（単語ごとの点数 −1〜+1、打ち消しの語）
- **重みの調整**：`config/weights.json`（期間ごとの「計算式とニュースの割合」と指標ごとの重み）。サイトの「的中率」を見ながら調整してください。

GitHub のサイト上でファイルを直接編集して保存すると、サイトに自動で反映されます。

## ローカルでの実行

```bash
npm ci
npm test                     # 単体テスト
npm run collect              # 実際にデータを集めて data/ に保存（ネットワークが必要）
npm run build:site           # _site/ を作る
npx playwright test          # 画面のテスト（テスト用データを使用）
```

## フォルダ

| パス | 内容 |
|---|---|
| `config/` | 銘柄・重み・検索語・単語辞書 |
| `src/core/` | 計算（指標・点数・予測・見出しの判定・まとめ方） |
| `src/collector/` | 株価とニュースの取得、的中率、毎日の処理 |
| `site/` | 画面（HTML / CSS / JavaScript） |
| `data/` | 自動実行で作られる JSON |
| `tests/` | テスト |
